7. DISCORD — FIX PERSISTENZA
============================================================
La V9 usa browserLocalPersistence PRIMA di effettuare signInWithCustomToken().

Inoltre:
- il Custom Token della callback viene tenuto temporaneamente in sessionStorage
  finché Firebase non completa davvero il login;
- viene richiesto un ID token dopo il login;
- il profilo UI viene messo in cache locale;
- un errore Firestore non forza il logout;
- viene mantenuto il nome dell'app Firebase "demon-public-user" per non rompere
  inutilmente eventuali sessioni precedenti.

ATTENZIONE:
se demonleaks.xyz presenta ancora un certificato HTTPS non valido in Safari,
prima va risolto GitHub Pages → Custom domain / Enforce HTTPS.
